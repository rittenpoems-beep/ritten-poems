01Philosophy / 理念

先建立理解，
再把它变成能力。

我不教快捷键式的“操作”，而是补一层很薄但很关键的计算机与工程基础，加上判断力：什么是合理的期待，怎么验证结果，出错时从哪里查起。

通过必要的计算机与工程基础，建立对 AI 的真实理解，再借助 Agent 把理解转化为实践能力。

这句话拆开来看是两句话，各自反对一种流行做法。

第一，我不认为所有人都必须先成为传统程序员，才有资格用 AI 做出东西。今天的工具确实让很多事的门槛下降了，一个不懂前端的人也可以让 Agent 帮他把内部小工具做出来。

第二，我也不认同完全跳过基础、只靠提示词就能掌握复杂系统。如果你不知道文件系统和路径是怎么回事，Agent 报错时你连它在说什么都不知道；如果你不理解上下文有成本，你就永远解释不清为什么同一件事今天成、明天败。

所以我教的不是“操作”，而是一层很薄但很关键的基础，加上判断力：什么是合理的期待，怎么验证结果，出错时从哪里查起。这些能力不会因为模型换代而贬值。

教学从哪里来

我有小学、初中数学一对一家教的实际经验，熟悉基础教学场景，也和大量家长直接沟通过。我知道一个概念要换几种说法孩子才会真的点头，也知道家长真正关心的是什么。

另一边，我持续在做 AI 科普短视频和开源项目。讲课用的每一个机制，基本都是我自己先踩过、再讲得出口的。

这门课是什么

《AI 认知理解入门课》：一对一，5 节课，每节 60 分钟。它是认知理解课，不是编程课——不教写代码，也不承诺孩子学完能用 AI 做出多厉害的作品。要验收的是另一样东西：孩子能不能向家长讲清楚 AI 的回答是怎么来的、为什么它会一本正经地说错话、哪些环节必须由人来把关。

五节课是一条链，不是五个话题

  • 认识人工智能：AI 是“从例子里学规律”的程序，和按固定规则办事的传统软件不一样
  • AI 为什么“会说话”：回答是根据上文逐词预测出来的，不是从数据库里查标准答案
  • AI 的边界：正因为靠预测生成，所以可能说得流畅却不真实，需要核实
  • AI 智能体（Agent）：给“大脑”配上工具、把任务拆开，它就能一步一步把事办完
  • 综合小项目：孩子自选题目，走完“拆任务 → 提问 → 获取 → 核实 → 整理”，最后向家长做一次小汇报

每一节课都在为下一节铺路：先分清 AI 和普通程序，才理解“从海量文字里学出规律”是什么意思；理解了回答是一个词一个词预测出来的，才真正明白它为什么会说错话，而不是只记住一句“AI 不可信”。

上完认知课之后

想真正动手的孩子还有第二阶段：从计算机基础讲到 Agent 应用与 AI 原生开发的进阶实践课。课时更多，安排单独沟通。

适合几岁

一般建议 9 岁（小学三年级）以上。年龄不是硬门槛，理解力才是——第一节课我会先评估，再调整讲法和节奏。

怎么判断听懂了

每节课最后由孩子用自己的话复述要点，我据此决定是否调整后续进度。答对不算懂，讲得出“为什么”才算。

家长会关心

我会直接谈 AI 的边界：什么时候该查、什么时候不该信、怎样不把思考外包出去。这是教学内容的一部分，不是免责声明。课后有一个约 10 分钟的观察小任务，不打分、不考试。

03Courses / 课程

两种入口。

一门给完全没基础、想把东西做出来的人打地基；一门给已经在用 Agent、但说不清它怎么工作的人。课序、每课能学到什么、已经发布到哪一节，都写在下面。

《0 计算机基础的 Agent 应用与开发入门》

12 课 · 三个阶段 · 中英双语 · 属于 B 线主课

敲代码这件事正在被 Agent 替代，但有三个环节没有被替代，反而更值钱：说清楚你要什么、理解软件大致怎么组成、判断结果对不对。这门课练的就是这三件事。

你可能经历过这样的场景：让 AI 帮你做一个小工具，它给出一大段代码，你复制、运行、报错，把报错贴回去，它改一版又冒出新问题。来回几轮之后，你已经不确定这个程序在做什么，也不知道结果能不能信。这不是因为你不够聪明——你手里缺的是两样东西：把想法准确表达出来的方法，和判断结果对不对的依据。

所以课程不从术语开始。它从你每天都在用的软件开始：外卖 App、记账本、手机闹钟。先弄清楚一个普通软件由哪些部分组成、怎么运转，再把 LLM、Agent 这些概念放到具体位置上。ChatGPT 和 Claude Code 本身也是软件，骨架和外卖 App 一样，只是“处理”那一步换成了大模型，并且多出了读写文件、调用工具的能力。

前五课几乎不讲 AI，讲的是软件本身：怎么把一句想法拆成输入、处理、输出和数据；一个程序由哪些模块组成、各负责什么；手机和远端服务器怎么分工；一个程序真正跑起来需要什么条件。第 6 课开始，模型才进入这条链。

阶段一 · 第 1–5 课

先看懂软件，再看懂 AI

你会问的问题：ChatGPT、Claude Code 也是软件，它们到底由什么组成？

  • 01已发布需求拆解：从想法到输入、处理、输出与数据拆解一个陌生的需求，指出规则和信息的遗漏
  • 02已发布软件的组成：程序、数据、模块、职责与基本流程按职责拆模块，并说清模块之间传递了什么
  • 03已发布软件之间的连接：网络、客户端与服务端、API、数据和服务画出本地与远端的分工、一次请求与响应，区分失败发生的位置
  • 04从设计到运行：理解软件如何组合并产生结果把模块和数据流对应到一个真正运行起来的小例子
  • 05计算机运行基础：文件、环境、依赖与操作系统解释软件运行需要什么，定位“换台电脑不能运行”的可能原因

阶段结束时：你能把一个陌生的小软件（包括一个 AI 工具）画成结构图，并说明它从接收输入到产生输出的完整过程。

阶段二 · 第 6–8 课

看懂 AI 与 Agent

你会问的问题：Agent 和聊天助手到底差在哪里？

  • 06理解 LLM：模型、输入输出、Token、上下文与外部应用区分模型与应用，解释它接收什么、产生什么、局限在哪里
  • 07理解 Agent：模型、工具、执行环境与工具调用区分聊天助手与 Agent，说明每个组成部分的职责
  • 08Agent 的运行机制：执行循环、状态、记忆、检索与失败原因跟踪一次执行，指出失败环节和可以检查的证据

阶段结束时：你能解释一个 Agent 做错事的几种可能原因，并知道该去哪里检查。

阶段三 · 第 9–12 课

用 Agent 做出东西

你会问的问题：如何让 Code Agent 替你做出一个能用的作品？

  • 09使用 Code Agent：需求表达、监督实现与结果验证写出明确的任务说明，检查实现并提出可验证的修改意见
  • 10独立设计方案：拆解陌生需求，设计架构与数据流为陌生需求画出结构与数据流，说明关键取舍
  • 11使用 Code Agent 实现项目：从设计到可运行、可验证的成果完成作品，并用事先定好的标准检查结果
  • 12结课考核：独立分析陌生需求，设计、实现并解释自己的作品提交作品、验证证据和个人解释，并根据反馈修订

阶段结束时：你完成一个可以运行、能自己验证的作品，并讲得清它是怎么来的。

《从会用 Agent，到真正理解 Agent》

九课 + 最终实践 · 全册已写完 · 写给已经在用 Agent 的人

如果你已经在用 Agent 帮你做事，但被这些问题卡住过：为什么它有时很聪明，有时又像忘了刚才说过的话？为什么它要问你“能不能执行这条命令”？为什么新开一个对话就不认识我了？为什么同一个模型放进不同工具，表现差很多？——这门课就是为这些现象写的。

九课是一条推理链，不是术语词典。上一课的结论会引出下一课的问题：模型只依赖这一次送进来的输入，那“记得我之前说的话”是怎么来的；上下文里除了文字还有工具调用和工具结果，那一个只会生成文字的模型怎么让程序动起来；一次调用只能做一次决策，那复杂任务为什么必须反复循环。最后两课把零件装回真实产品，再换到设计者的位置。

每一课按同样九段推进：本课要解决的问题、先给直觉、正式解释、和上一课的连接、一个真实案例、一个小实验、常见误解、本课验收、一句话带走。一课 20～30 分钟，实验用你手里现有的工具就能做，不需要额外搭建环境。

学完之后你能做到

  • 向一个完全不懂 Agent 的人解释 LLM、Context、Session、Tool Calling、Agent Loop、Memory、Harness 分别是什么、怎样互相咬合
  • 遇到 Agent 出错、忘记、绕圈、乱改时，大致判断问题出在哪一层
  • 自己设计一个小实验去验证一个说法，而不是只能背定义

验收方式

不是背下来，而是你能不看讲义，把它讲给别人听。

  • 01什么是 Agent我每天用的 Codex、Claude Code，到底是什么？
  • 02LLM 到底在做什么如果 Agent 的“大脑”是 LLM，那 LLM 自己在做什么？
  • 03没有跨轮状态的模型，为什么聊天像有记忆模型只处理当前输入，那“记得”是从哪来的？
  • 04Agent 为什么能操作电脑只会生成文字的模型，怎么打开文件、执行命令、调用 API？
  • 05为什么 Agent 必须不断循环为什么不能调用一次工具，然后就结束？
  • 06Harness：模型外面那一大套做了什么我输入的一句话，中间到底经过了哪些东西？
  • 07Agent 为什么会“忘记”上下文可以保存历史，为什么它还是忘东西？
  • 08为什么需要检索历史信息那么多，难道每次都全部塞给模型？
  • 09从这些重新理解 Agent Framework如果让我自己设计一个 Agent，我需要什么？
  • 实践画出你的 Agent，并解释一次完整任务一次任务里，哪部分是模型、哪部分是系统、哪些信息还存在？

家长问

孩子还小，学 AI 是不是太早？

如果指的是提前学编程语法，那确实太早。我教的是理解、信息素养和动手表达，用孩子能懂的案例完成。真正该考虑的是他现在的认知能不能把一件事讲清楚。

学员问

我不会写代码，能学 B 线吗？

可以，前提是你愿意补上很薄的一层基础：文件、路径、命令行、数据是怎么流动的。这些不需要几年训练，但绕开它们，Agent 的失败你永远看不懂。
